# 拾级 · 六级研习室

一个为大学英语六级（CET-6）打造的系统化学习网站。纯前端、零依赖，学习数据保存在浏览器本地。核心功能可离线运行；真题听力音频在线流播，也可载入本地音频。

名字取自「拾级而上」：把六级拆成每天可以完成的一小步。

**v1.2.3 重点更新**
- 接入 **33 套 / 825 题**公开授权的真题听力（2016.12–2025.12），含逐句中译、选项、答案、依据句、原声音频流。
- 新增 **624 个六级听力进阶词**（基于 39 套真题听力原文统计），其中 **119 个高频核心**（出现 ≥3 套）；词频数字全部可复核。
- 新增 **3,991 个六级大纲全词**查阅表。
- 听力新增：分节练习、盲听/逐句、0.6–0.75x、循环、语流提示、点词查义、跟读、当前句听写、真题依据句。
- 记忆盒从 134 个精讲词扩展到 745 个（134 精讲 + 611 听力进阶）。

> 重要：真题听力来自第三方公开资源（CC BY 4.0，含权利边界说明）；其余阅读、写作与原创听力仍是原创仿真材料。详见 `DATA_SOURCES.md` 与 `THIRD_PARTY_NOTICES.md`。

## 快速开始

```bash
# 任选其一
node serve.js            # 零依赖本地服务器，默认 http://127.0.0.1:5173
npm start                # 同上
node serve.js --lan      # 允许同一 Wi-Fi 下的朋友访问，控制台会打印局域网地址
python -m http.server 5173
```

然后打开 <http://127.0.0.1:5173>。

> 建议通过本地服务器访问，而不是直接双击 `index.html`。语音合成、麦克风跟读和 PWA 离线缓存都需要 `http://localhost` 或 HTTPS 环境。

浏览器建议：**Chrome / Edge**（语音合成与语音识别支持最好）。

### 让同一 Wi-Fi 下的朋友访问

```bash
node serve.js --lan
```

Windows 用户也可以直接双击根目录的 `启动局域网.bat`（默认 5173 端口；若端口被占用，可在终端用 `启动局域网.bat 5174` 换端口）。

控制台会打印类似 `http://192.168.1.23:5173` 的局域网地址；把该地址发给同一 Wi-Fi 下的朋友即可。首次运行若弹出 Windows 防火墙提示，勾选“专用网络”并允许 Node.js 访问；没有弹窗时，可在「Windows Defender 防火墙 → 允许应用通过防火墙」中给 Node.js 勾选“专用”。

> 局域网共享走 HTTP，不属于安全上下文，PWA 安装/离线缓存和麦克风跟读可能不可用；校园网或访客 Wi-Fi 还常开启客户端隔离，朋友可能打不开。长期使用或需要手机安装，建议部署到 HTTPS 静态托管。

## 已实现的五大模块

### 1. 词汇与短语核心库
- **记忆盒共 745 个词**：134 个精讲词（大纲基础 30、六级高频 56、熟词生义 24、高阶 24）+ 611 个新加入的六级听力进阶词。
- **六级听力词库 624 个**：按 39 套 2016–2025 真题听力原文统计；其中出现 ≥3 套的 **高频核心 119 个**。每个词显示音标、释义、出现次数、覆盖套数，可发音并进入记忆盒。
- **大纲全词表 3,991 个**：用于查阅、搜索和定位；不强迫全部背完，精讲词与听力高频词才进入记忆盒。
- 每个精讲词条包含音标、词性、释义、原创仿真例句、高频搭配、近反义词、词根或熟词生义提示。
- **20 组易混辨析**（affect/effect、adapt/adopt、principal/principle 等），带区别说明、双例句与「测一测」小测。
- **24 个高频搭配** + 可交互「搭配星图」。
- **艾宾浩斯记忆盒**：答对升盒，复习间隔 1/2/4/7/15 天；答错回到第一盒。
- 三种复习模式：**听音辨义 / 拼写测试 / 看句填空**，支持键盘 1–4、空格重播、回车进入下一题。

### 2. 听力实验室
- **真题精听：33 套 / 825 题 / 5,196 个逐句单元**（2016.12–2025.12）。提供原声音频流、逐句中译、选项、答案、原文依据句与分节时间轴；778 题有可靠依据句，其余 47 题只给选项、不强行标注依据。
- **分节精听**：一次只练一个 Conversation / Passage / Lecture，不必一上来硬听 25 题。
- **听得懂训练**：0.6–1.5x 变速、逐句循环、盲听、原文/中文开关、当前句点词查义、语流提示（缩写/弱读）、跟读评测、当前句听写。
- **真实考场逻辑**：题目问句在音频中播报，卷面只有选项；做题模式必须使用真题音频或本地音频，合成语音无法替代题目。
- **原创仿真听力 6 套**：长对话 2、听力篇章 2、讲座 2，共 25 题；保留逐句精听、完整听写、信号词标记，可离线使用 TTS。

### 3. 阅读与长难句
- **12 个逐段标注的长难句**：主语、谓语、宾语、表语、状语、定语从句、同位语、插入语等，支持「只看骨架」「成分标签」「译文」切换；附可视化语法树与语法点。
- **自定义拆句**：粘贴任意长句，本地启发式统计词数、从句密度、平均句长并识别连接结构。只做辅助，不冒充自动句法分析。
- **选词填空 2 篇**：15 词库、10 空，点击填空，附词性提示与逐空解析。
- **长篇匹配 2 篇**：关键词定位、扫读计时、段落匹配与依据句解析。
- **仔细阅读 3 篇**：限时、题型标签（细节/主旨/推断/词义/态度），以及独创的**依据句定位**——先点原文证据句再作答，分别批改「答案」与「定位」。

### 4. 写作与翻译工坊
- **3 道写作题** + 3 篇参考范文（高亮可迁移表达）。
- **4 道翻译题**（历史/文化/经济/社会），含参考译文、术语表、语块对齐。
- **56 条主题语料**：中国历史、文化、经济、社会四大主题。
- **42 组高级替换**、**20 个高分句式**、**6 个整篇结构模板**，均可复制。
- **本地规则批改引擎**：
  - 拼写、主谓一致、冠词、不可数名词、比较级、连词叠用、搭配、标点等 30+ 条规则；
  - 任务完成、语言准确、词汇丰富、句式语法、衔接结构五维评分，折算 15 分制；
  - 错误逐处标记、问题清单、可逐条应用的高级替换；
  - 写作/翻译草稿自动保存在浏览器；
  - 清楚标注「练习估算，不是官方分数」。
- **AI 深度批改（可选）**：在设置中配置 OpenAI 兼容接口后，可让模型做一次独立于规则引擎的二次批改。未配置时完全本地运行。

### 5. 全真模考与数据分析
- **130 分钟四段式考场**：写作 30 → 听力 30 → 阅读 40 → 翻译 30，严格按六级结构。
- **严格模式**：按顺序作答、不可返回、听力只播放一次、倒计时结束自动推进。
- 交卷后自动判分：听力 25 题 / 阅读 30 题 / 写作与翻译规则引擎档位，按 710 分制加权折算。
- **智能错题本**：按模块与错因自动归档，支持筛选、解决、删除、回到原题。
- **能力雷达**：词汇、听力、阅读、写作、翻译五维掌握度。
- **分数区间预测**：基于训练完成度、正确率、作文档位与模考成绩，附透明算法与置信度说明；样本不足时明确显示「待测」。
- 学习热力图、模考趋势、错因环图、复习负荷预测、成就系统、可打印学习报告。

## 额外功能（超出需求清单）

- **听力高频词独立页**：按“覆盖套数 → 出现次数”排序，显示 119 高频核心 / 624 六级进阶 / 600 全部实词；可只背核心组。

- **依据句定位训练**：仔细阅读把“答对”与“找对证据”分开计分；真题听力也显示原文依据。
- **真题听力引导线**：先词 → 盲听一节 → 逐句 → 做题，一键切换。

- **AI 学伴**：本地知识库检索（可离线），可选接入 LLM；优先给出站内资料与链接。
- **可打印诊断报告**、**学习数据导出/导入**、**PWA 离线缓存**、**日间/夜读双主题**。
- **深色模式、响应式移动端、键盘快捷键、草稿自动保存**。

## 数据与隐私

- 学习数据保存在浏览器 `localStorage`，键名：`cet6studio.v1`。
- 换设备/浏览器前，请在「设置 → 数据管理 → 导出 JSON」备份。
- 学习数据只在本机。打开真题听力时，音频会请求 GitHub 媒体地址；启用 AI 增强后，问题、文本与检索片段会发送到你配置的接口。
- API Key 仅保存在当前浏览器 localStorage，不会由本站上传到其他地方。公共电脑使用后请清除。
- 除真题音频流外，页面与文本数据可离线缓存；下载原音频后可在真题页“载入本地音频”，实现离线做题。

- 写作/翻译分数由本地规则引擎估算；模考总分为线性折算。六级官方计分使用常模转换，本站结果**仅作练习参考**，不能替代官方成绩或教师评分。
- 规则引擎擅长发现拼写、主谓一致、搭配、标点等表层问题；对论证深度、语义连贯和语气细微差别的判断有限。请结合范文、错题与人工反馈使用。
- 分数预测在样本不足时显示「待测」；已有数据时给出区间与置信度，算法在页面上公开说明。

    ├── css/main.css         # 设计系统与页面样式
    ├── css/listening-real.css
    ├── img/                 # Logo 与 PWA 图标

## 本地开发

```bash
node --version    # 建议 18+
node serve.js     # http://127.0.0.1:5173
```

- 修改 `assets/js/data/*` 即可扩充题库；页面会自动读取。
- 真题听力数据与词频的生成口径见 `DATA_SOURCES.md`；`tools/build-content.mjs` 与 `tools/frequency.mjs` 需要自行准备第三方源文件（不在仓库内），不会在运行时联网生成。
- 新增词条需保持字段结构（`id/word/phonetic/pos/tier/senses/example/collocations/synonyms/tags`）。
- 扩充听力/阅读时，请同步保证 `question.answer`、`question.evidence` 与数据索引一致。
- 生产部署：把整个目录放到任意静态托管（GitHub Pages、Netlify、Nginx）即可；PWA 需 HTTPS。

## 适用与边界

这是一个**练习与诊断工具**，不是真题库，也不是自动阅卷的替代品。它最适合：
- 每天 30–60 分钟的词汇复习与精听；
- 阅读长难句、定位证据句、积累写作翻译语料；
- 用模考暴露短板，再用错题本和专项训练闭环。

如果目标是冲高分，最终仍需要：真实真题训练、教师/同伴反馈，以及按考试节奏完成整套卷。
