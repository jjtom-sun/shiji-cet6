## 1. Real CET-6 listening resources (transcripts, options, answer keys, translations, timestamps)

- **Title:** CET-6 Listening Resources & Analysis v1.0.0
- **Author:** Leif / Ysoseri1224
- **Upstream repository:** <https://github.com/Ysoseri1224/CET-6-Listening-10-Years-Resources-and-Analysis>
- **Archival mirror used for retrieval:** <https://github.com/getfine333-ux/cet6-listening-study>
- **DOI:** <https://doi.org/10.5281/zenodo.20474009>
- **Licence declared by the upstream publisher for the resource files:** **CC BY 4.0** — <https://creativecommons.org/licenses/by/4.0/>
- **What we used:** English transcripts, printed options, answer keys, machine translations and timing metadata for 33 selected sets (2016.12–2025.12).
- **Changes made:** sentence segmentation; evidence-marker alignment; OCR/format cleanup of options; selection/exclusion of incomplete or mismatched sets; addition of TTS/audio UI, quizzes, SRS links and study guidance; no audio files are redistributed.
- **Audio:** played by streaming the public files from the mirror's Git LFS storage (`media.githubusercontent.com`). Audio is not copied into this repository. If the stream is unavailable, the site falls back to browser speech synthesis for transcript study, or the user can load an audio file they obtained from the source.
- **Excluded sets:** `2016.12` set 1/2 and `2017.06` set 1/2 (upstream states audio/transcript correspondence is unreliable), `2019.12` set 3 (no question file), `2022.06` (only part of the answer key is standard). The complete 39-set corpus is still used for the **word-frequency statistics**, because transcript-only word counts do not depend on the question file.
- **Rights caveat (from the mirror's notice):** CET-6 examination content may contain material whose underlying rights belong to examination bodies, publishers, speakers or other third parties. The CC BY 4.0 declaration is the immediate upstream publisher's declaration, not an independent warranty. This project uses the material for non-commercial educational study and preserves attribution. Rights holders may request correction, additional attribution or removal.

## 3. Original site content

The 134 hand-authored vocabulary entries, the six original simulated listening sets, the reading passages and questions, the writing prompts, the model essays and reference translations, and the UI are original educational content created for this project. They are not official CET-6 papers or official answers.

“CET-6” / “大学英语六级” refers to the examination administered by the relevant examination authority. This site is an independent study tool and is not affiliated with or endorsed by that authority.
